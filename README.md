# 🎮 Python Mini Games

A collection of small, beginner-friendly command-line games and utilities written in Python — built for practicing core Python concepts like loops, conditionals, dictionaries, and randomization.

![Python](https://img.shields.io/badge/Python-3.x-3776AB?style=flat&logo=python&logoColor=white)

## 📂 Games Included

| File | Description |
|---|---|
| [`Rock_Paper_Scissor.py`](Rock_Paper_Scissor.py) | Classic Rock–Paper–Scissors against the computer, with input validation and a win/lose/draw check. |
| [`Snake_Water_Gun.py`](Snake_Water_Gun.py) | A 3-way variant of Rock-Paper-Scissors (Snake drinks Water, Water damages Gun, Gun kills Snake). |
| [`Perfect_Guess_.py`](Perfect_Guess_.py) | A number-guessing game — the computer picks a random number (1–100) and gives "higher/lower" hints until you guess it, tracking your attempts. |
| [`Calculator.py`](Calculator.py) | A simple command-line calculator that evaluates a math expression you type in. |

## 🚀 How to Run

Each game is a standalone script. Clone the repo and run any file with Python 3:

```bash
git clone https://github.com/KKunal-007/Python-Mini-Games.git
cd Python-Mini-Games
python Rock_Paper_Scissor.py
```

Or run any of the others the same way:
```bash
python Snake_Water_Gun.py
python Perfect_Guess_.py
python Calculator.py
```

No external libraries required — just the Python standard library (`random`).
